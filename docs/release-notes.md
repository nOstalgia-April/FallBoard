FallBoard — Push Prototype v0.1

- 固定 3×3、2v2，三个可解预设关卡。
- 接触面比较、击退、阻挡、推落死亡；每方共享 2 AP。
- 确定性规则 AI、20 轮僵局、胜负与重开。
- 中文界面、攻击预览、接触面数字高亮、方向箭头与位移动画。
- Windows 独立运行包与单线程 Web 包。

下载 `FallBoard-Windows.zip`，解压后双击 `FallBoard.exe` 即可试玩。Web 包需要通过 HTTP 服务器打开。Godot 工程请用 4.5.1 标准版打开。

此为玩法验证原型。规则与界面流程已自动检查；真人乐趣验证与 Windows 实机验收仍需完成。
