# FallBoard v0.1 试玩记录

至少邀请 3 名未参与设计的玩家，每人依次体验 3 个关卡。第一次行动前仅展示游戏内操作说明，不口头提示解法。卡住时可以让玩家自己点击「查看本关提示」，记录是否使用提示。

## 每位玩家填写一份

玩家编号：________　日期：________　是否经常玩战棋 / 桌游：________

| 关卡 | 通关 / 失败 / 僵局 | 用时 | 重开次数 | 是否查看提示 | 印象最深的一步 |
|---|---|---|---|---|---|

1. 第一关后：不点击攻击，能否指出一个目标会被推落、被阻挡或攻击失败？记录判断及理由。
2. 第二关后：是否曾在「移动」与「攻击」之间犹豫？是哪一步？
3. 第三关后：是否意识到队友也会阻挡？两枚棋子分别起了什么作用？
4. 用 1—5 分评价：规则易懂程度、站位选择的意义、想再玩一局的程度。
5. 哪次实际结果与你的预期不同？预览是否解释清楚？
6. 如果只改一件事，你希望改什么？
